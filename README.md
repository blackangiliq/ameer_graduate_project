# IAM Gateway — نظام إدارة الهوية والوصول والمصادقة

**Identity and Access Management (IAM) and Authentication**

مشروع تخرج متكامل يبني بوابة موحّدة لإدارة هويات موظفي مؤسسة وصلاحياتهم، تطبّق المصادقة متعددة العوامل (MFA)، والتفويض المبني على الأدوار (RBAC)، وإدارة دورة حياة الحساب، وإدارة الجلسات، وسجل تدقيق كامل.

| | |
|---|---|
| **الخادم** | Node.js 22 + Express 5 |
| **قاعدة البيانات** | SQLite (المحرّك المدمج في Node.js `node:sqlite`) |
| **الواجهة** | HTML + CSS + JavaScript (بدون أطر عمل) — عربية بالكامل RTL |
| **المؤسسة التجريبية** | شركة الرافدين للحلول التقنية — بغداد (22 موظفاً، 7 أقسام، 770 حدث تدقيق) |
| **الاختبارات** | 23 اختباراً آلياً (`npm test`) — جميعها ناجحة |

## التشغيل خلال دقيقة

المتطلبات: **Node.js 22.13 أو أحدث** (لا يحتاج تثبيت قاعدة بيانات منفصلة).

```bash
git clone https://github.com/blackangiliq/ameer_graduate_project.git
cd ameer_graduate_project
npm install
npm start
```

افتح المتصفح على **http://localhost:3000** — عند أول تشغيل تُنشأ قاعدة البيانات وتُملأ تلقائياً بالبيانات التجريبية.

| الأمر | الوظيفة |
|---|---|
| `npm start` | تشغيل الخادم |
| `npm run seed` | حذف البيانات وإعادة إنشاء البيانات التجريبية من جديد |
| `npm run totp` | طباعة رمز التحقق الحالي (6 أرقام) لحسابات MFA التجريبية — بديل عن تطبيق الهاتف |
| `npm test` | تشغيل الاختبارات الآلية الـ 23 |

## كيف تحقّق المشروع من IAM؟

| ركيزة IAM | التطبيق في المشروع |
|---|---|
| **التعريف (Identification)** | هوية فريدة لكل موظف: اسم مستخدم + بريد + قسم + مسمى وظيفي |
| **المصادقة (Authentication)** | كلمة مرور مُجزّأة بـ bcrypt (cost 12) + سياسة كلمات مرور + **TOTP (RFC 6238)** مبنيّ يدوياً + رموز استرداد + قفل الحساب بعد 5 محاولات + تحديد معدل الطلبات |
| **التفويض (Authorization)** | **RBAC**: مستخدم ← أدوار ← صلاحيات بصيغة `resource:action`، الرفض الافتراضي، أقل الصلاحيات، فصل المهام، منع تصعيد الصلاحيات، تُقرأ الصلاحيات من قاعدة البيانات مع كل طلب |
| **إدارة الجلسات** | JWT قصير العمر (15 دقيقة) في الذاكرة + Refresh Token في Cookie من نوع HttpOnly/SameSite=Strict مع **التدوير وكشف إعادة الاستخدام** + إنهاء فوري للجلسات |
| **دورة حياة الهوية** | Joiner (إنشاء/موافقة) ← Mover (تغيير الأدوار) ← Leaver (تعطيل + إنهاء الجلسات) |
| **المساءلة (Accountability)** | سجل تدقيق لكل حدث أمني: من، ماذا، على ماذا، النتيجة، العنوان، الجهاز، الوقت — مع تصفية وتصدير CSV |
