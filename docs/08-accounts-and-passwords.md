## 1. المصادقة الثنائية (MFA) للحسابات المفعّلة

الحسابات `ali.alsaadi` و`zainab.alobaidi` و`laith.alobaidi` مفعّل عليها التحقق بخطوتين. بعد إدخال كلمة المرور يُطلب رمز من 6 أرقام. للحصول عليه هناك ثلاث طرق:

**الطريقة الأولى (الأسهل):** في الطرفية داخل مجلد المشروع نفّذ الأمر التالي، وأدخل الأرقام الستة الظاهرة:

</div>

```bash
npm run totp
# TOTP code: 482913   (valid for 17s)
```

</div>

## 3. حسابات توضّح حالات خاصة

| الحساب | الحالة | ماذا يحدث عند محاولة الدخول |
|---|---|---|
| `abbas.alsudani` | **مقفل** بعد هجوم تخمين محاكى من `45.155.205.233` | HTTP 423 «الحساب مقفل مؤقتاً» حتى مع كلمة المرور الصحيحة. يُفتح بعد 15 دقيقة، أو فوراً من `sara.almusawi` عبر صفحة المستخدمين ← «فك القفل» |

| `hiba.alnuaimi` و`ali.alfatlawi` | **بانتظار الموافقة** (تسجيل ذاتي) | HTTP 403 «حسابك بانتظار موافقة مدير الهويات» |
| `shahad.aljanabi` | **كلمة مرور مؤقتة** | تُحوَّل إجبارياً إلى صفحة تغيير كلمة المرور، وكل طلب آخر يُرفض |
